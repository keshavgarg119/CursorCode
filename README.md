# ⚡ CursorCode

> **CursorCode** is a sleek, modern, neon-themed live code editor for HTML, CSS, and JavaScript with instant preview, an interactive in-browser console, resizable panels, and keyboard shortcuts.

## ✨ Features

- 🎨 **Modern Neon Dark UI**: Glassmorphic styling, vibrant glowing accents, and smooth gradient background animations.
- ⚡ **Instant Live Preview**: Real-time rendering of HTML, CSS, and JS code inside a secure sandboxed iframe.
- 🖥️ **Built-in Virtual Console**: Intercepts `console.log`, `console.warn`, `console.error`, and `console.info` messages right below the live preview.
- 🗂️ **Tabbed Editor Interface**: Easily switch between `index.html`, `style.css`, and `script.js` code panels.
- 📐 **Resizable Split Layout**: Drag-and-drop divider handle to customize the editor vs. preview workspace sizes.
- 📥 **One-Click Download**: Export your code bundle directly to your computer.
- ⚡ **Auto-Run & Shortcuts**: Toggle live auto-update or manually execute with `Ctrl` + `S`.

---

## 🛠️ Tech Stack

- **Structure**: Semantic HTML5
- **Styling**: Vanilla CSS3 (CSS Custom Properties, Glassmorphism, Animations, Flexbox/Grid)
- **Logic**: Vanilla JavaScript ES6+ (Iframe `srcdoc` manipulation, `postMessage` cross-frame API, DOM event handling)
- **Deployment**: Static web host compatible (GitHub Pages, Vercel, Netlify)

## 🚀 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/keshavgarg119/CursorCode.git
   cd CursorCode
   ```

2. **Run locally**:
   Simply open `index.html` in your web browser! No Node.js, npm, or build process required.

| Shortcut | Action |
| :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> | Run / Update Live Preview |

## 🌐 Deployment

### Deploy on GitHub Pages

1. Go to your repo **Settings** -> **Pages**.
2. Set **Branch** to `main` and **Folder** to `/ (root)`.
3. Click **Save**.

Your live URL will be available at:  
👉 **`https://keshavgarg119.github.io/CursorCode/`**
